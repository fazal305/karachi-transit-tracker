# Karachi Transit Tracker

A data-driven public transport visualization app for Karachi, built with Leaflet, OpenStreetMap, Open-Meteo, Bootstrap 5, jQuery, and vanilla JavaScript.

This project visualizes Karachi BRT routes, stations, weather conditions, timetables, route planning, and clearly labeled simulated bus movement.
